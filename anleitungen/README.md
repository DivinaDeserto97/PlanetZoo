# Anleitungen für Nutzer und neue Mitwirkende

Dieser Ordner ist für **leicht verständliche Schritt-für-Schritt-Anleitungen** gedacht. Du musst den Quellcode nicht verstehen, um diese Anleitungen zu benutzen.

Die Texte sind bewusst so aufgebaut, dass sie auch als Grundlage für **YouTube-Anleitungsvideos** verwendet werden können: Ziel erklären, Vorbereitung zeigen, Schritte durchführen und am Schluss kontrollieren.

## Welche Anleitung brauche ich?

| Ziel                                     | Anleitung                                                                  |
| ---------------------------------------- | -------------------------------------------------------------------------- |
| Ein neues Tier hinzufügen                | [`NEUES-TIER-ANLEGEN.md`](NEUES-TIER-ANLEGEN.md)                           |
| Daten eines vorhandenen Tiers ändern     | [`TIER-BEARBEITEN.md`](TIER-BEARBEITEN.md)                                 |
| Bilder, Tierstimmen oder Videos ergänzen | [`MEDIEN-EINFUEGEN.md`](MEDIEN-EINFUEGEN.md)                               |
| Ein Tier vor dem Abschluss kontrollieren | [`PlanetZoo2-Tierdaten-Checkliste.md`](PlanetZoo2-Tierdaten-Checkliste.md) |

## Wenn du technische Details brauchst

Die technische Referenz für Entwickler liegt in [`../dokumentation/`](../dokumentation/). Dort findest du unter anderem den vollständigen Aufbau der Tier-JSON, den Projektaufbau, Bot-/GitHub-Actions-Dokumentation und die automatisch erzeugte Ordnerstruktur.
